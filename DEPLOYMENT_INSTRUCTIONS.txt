🚨 TROUBLESHOOTING RAPIDE

ERREUR: Application won't start
  → Vérifier JWT_SECRET_KEY dans variables
  → Vérifier DATABASE_URL
  → Vérifier les logs (affichent l'erreur réelle)

ERREUR: Database connection refused
  → Vérifier les credentials MySQL
  → Vérifier que MySQL est accessible
  → Vérifier le firewall

ERREUR: Build failed
  → Vérifier que le code compile en local: mvn clean compile
  → Vérifier les dépendances: mvn clean install
  → Vérifier les logs du build

ERREUR: Frontend CORS errors
  → Ajouter à variables: CORS_ALLOWED_ORIGINS=https://your-frontend.url
  → Restart l'application
